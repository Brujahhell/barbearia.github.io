# Black Crown Barbearia

Landing page moderna e responsiva desenvolvida para uma barbearia fictícia, criada como projeto de demonstração para portfólio e apresentação comercial de desenvolvimento de sites.

O projeto foi pensado para transmitir uma identidade visual **masculina, sofisticada e premium**, utilizando uma combinação de preto, tons dourados e tipografia de destaque.

# Sobre o projeto

A **Black Crown Barbearia** é um conceito de site institucional para uma barbearia que deseja apresentar seus serviços, preços e diferenciais de forma profissional, além de facilitar o contato e o agendamento de clientes.

O layout foi desenvolvido com foco em:

* Experiência do usuário
* Design moderno e elegante
* Responsividade
* Apresentação dos serviços
* Conversão de visitantes em clientes
* Facilidade de contato pelo WhatsApp
* Estrutura preparada para personalização

## Funcionalidades

* Página inicial com seção Hero
* Apresentação da barbearia
* Serviços oferecidos
* Tabela de preços
* Galeria de imagens
* Depoimento de cliente
* Área de agendamento
* Informações de localização
* Integração visual com Instagram
* Botão flutuante do WhatsApp
* Menu responsivo para dispositivos móveis
* Animações e efeitos de interação

## Identidade visual

A identidade visual foi construída utilizando:

* Preto como cor principal
* Dourado como cor de destaque
* Tons de cinza para textos secundários
* Tipografia de impacto para títulos
* Cards e elementos com estética minimalista

## Responsividade

O projeto possui adaptações para diferentes tamanhos de tela.

O layout conta com breakpoints específicos para tablets e smartphones, incluindo:

* Menu mobile
* Alteração da quantidade de colunas
* Formulários adaptados
* Botões em largura total
* Ajustes de tipografia
* Galeria responsiva
* Footer adaptado para telas menores
